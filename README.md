# Pixel Miner

## Description
A fast‑paced arcade game where you control a mining ship at the bottom of the screen, shoot falling asteroids and collect the minerals they drop. Survive as long as you can and aim for a high score.

## Installation
1. Download or clone the repository.
2. Open `index.html` in any modern browser (desktop or mobile).

## Controls
- **Desktop**: Arrow keys (← / →) to move, Space bar to fire.
- **Mobile**: Touch the left/right arrows on the screen, tap the fire button.

## Gameplay
- Asteroids fall from the top with random speed.
- Shoot them with lasers; each destroyed asteroid gives points.
- Occasionally a mineral drops; collect it by catching it with the ship for bonus points.
- The game ends when an asteroid reaches the bottom.

## Restart
When the game is over, click/tap the **Restart** button to play again.
